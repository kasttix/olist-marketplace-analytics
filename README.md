# Olist Marketplace Analytics

Аналитический проект по данным e-commerce маркетплейса Olist.

Проект включает подготовку данных, SQL-витрины, EDA на Python, расчёт продуктовых метрик, retention-анализ, проверку гипотез и интерактивный Power BI dashboard.

## Цель проекта

Проанализировать данные маркетплейса Olist и определить:

- какие факторы влияют на выручку;
- как клиенты возвращаются за повторными покупками;
- как доставка влияет на отзывы и клиентский опыт;
- какие категории, регионы и продавцы требуют внимания;
- какие продуктовые и операционные решения могут улучшить бизнес-метрики.

## Стек

- Python: Pandas, NumPy
- SQL: PostgreSQL
- BI: Power BI
- Визуализация: Matplotlib, Seaborn
- Среда: Jupyter Notebook
- Дополнительно: Git, Docker, Excel

## Данные

В проекте используется датасет Olist Brazilian E-Commerce.

Данные включают информацию о:

- заказах;
- клиентах;
- продавцах;
- товарах;
- оплатах;
- отзывах;
- доставке;
- географии.

## Ключевые метрики

В проекте будут рассчитаны:

- Revenue;
- GMV;
- AOV;
- CSAT;
- Repeat Purchase Rate;
- Retention;
- Late Delivery Rate;
- Cancellation Rate.

## План анализа

1. Подготовка структуры проекта.
2. Загрузка и проверка качества данных.
3. Создание аналитических витрин в SQL.
4. EDA и анализ бизнес-метрик в Python.
5. RFM-сегментация клиентов.
6. Когортный анализ retention.
7. Анализ влияния доставки на отзывы.
8. Проверка гипотез.
9. Дизайн A/B-теста.
10. Создание Power BI dashboard.
11. Формирование выводов и бизнес-рекомендаций.
